# The tinkr stylesheet

This function returns the path to the tinkr stylesheet

## Usage

``` r
stylesheet()
```

## Value

a single element character vector representing the path to the
stylesheet used by tinkr.

## Examples

``` r
tinkr::stylesheet()
#> [1] "/github/home/R/x86_64-pc-linux-gnu-library/4.6/tinkr/stylesheets/xml2md_gfm.xsl"
```
